# Landing (/) surface brief

Scope: public landing `/` and the shared public design system every public route inherits.
Mode: Persuade. Audience: SUST students deciding to show up or join; members sharing portfolios; sponsors and
speakers checking the club is real. Action: reserve a seat at the next event (working RSVP island in the first
viewport); secondary, join. Proof: the snapshot (events, committee, posts, talks, sponsors). No invented claims.
Why replaced (2026-11-02): the user found the rickshaw-backboard world funny, "not whole fun type, it's a
university website, not a school's website". Brief pinned: professional, credible, university-grade, calm,
precise; restrained technical motif; Bangla wordmark small; brand green primary, brand red sparing.
Decided unattended (subagent, no question channel); code-led (no image generation).

Grounded list, by resonance: 1 ICPC contest scoreboard; 2 conference proceedings paper (ACM/IEEE two-column);
3 university identity programme (institutional Swiss grid); 4 engineering drawing sheet (title block, grid
references, hairlines, dimension lines); 5 component datasheet; 6 SUST red-brick campus and tea hills;
7 terminal/editor (tool slot). Assigned: 4. Challengers all declined (secession page, ligne claire, papercut,
Versailles, drum machine, CRT arcade): each loses audience identification and product clarity to a sober brief.

Mid-build user feedback (2026-11-02), binding: the ASCII/binary plot was rejected as a gimmick ("silly, makes no
sense"); technical elements must carry real meaning or be ambient. Then "bring some technical vibe": a terminal
prompt line, the next event as a code window, numbered section heads, a contribution graph from real data, mono
metadata, syntax-highlighted code. Sticky compact header. Committees of ~30 seats grouped by kind of post.

## Direction contract

THESIS: Binary SUST reads like a well-made engineering document and a developer tool: hairline structure, precise
metadata, real data shown the way engineers show it. Refuses the category default (dark neon terminal hero, split
hero over a card row) and the SaaS gradient template; refuses any decoration that is not data or ambient.

OWN-WORLD: Drafting-film white (light) / night graphite (dark), neutrals tinted to the brand green hue. Brand green
is the one action and "active" colour; brand red only for the live dot. One 1px hairline weight for every rule,
border and frame; no shadows, no gradients, no glass. Archivo semi-expanded for display, normal width for text;
JetBrains Mono for dates, handles, labels, code; Anek Bangla only for বাইনারি. Square portraits, 4-6px radii.

STORY: The visitor sees the club name, the Bangla wordmark and motto, the mission as the output of a typed
`binary --mission` prompt, and the next event as a readable code window with a real Reserve button. Scroll: club
numbers beside a contribution graph of real activity, the dated schedule, the committee officers, an advisor talk
on a sunken band, latest writing, sponsors in a hairline grid, the join close.

FIRST VIEWPORT: Full-width hero over a faint engineering grid with a pointer-following glow (ambient only). Left:
"Binary SUST" in Archivo semi-expanded at clamp(3rem, 9vw, 6rem), বাইনারি + motto, the prompt line typing once,
the mission at 1.25-1.5rem, Join (primary) and All events. Right (25rem): the next-event window: title bar, kind
tag, event/when/where/about rows, Reserve button (primary action) and details link.

FORM: engineering drawing sheet, position 4 of 7; seed:e61b5fbedacdd81b. Raises: from ligne claire, one unvarying
line weight and colour saved for the action; from secession page, ornament lives only in the background, never in
the text column; from papercut, depth by flat plane steps, never shadow; from Versailles, every section heading
hangs on the same left axis with its mono index; from drum machine, the schedule reads as one unbroken dated line.
